Detailed Description

Resource is an interface for reading inside a file, but is not supposed to write to the file it wraps. The Resource class is created by passing a path to an existing binary (such as a zipped archive or a Qt resource file).

The resource name can be set at any time using setName() or during construction. The segment supplied during construction represents the offset and size of the resource inside the file.
